Here is a **combined assignment** that covers **HTML, JavaScript, JavaScript OOP, and MySQL CRUD queries**. It is suitable for beginners to intermediate students and is designed as a mini project.

# Assignment: Student Management System

## Objective

Develop a simple **Student Management System** using HTML, JavaScript, JavaScript OOP concepts, and MySQL CRUD queries.

---

# Part 1 – HTML (20 Marks)

Create the following webpage.

### Requirements

* Create a webpage with the title **Student Management System**
* Add a heading.
* Create a form containing:

| Field         | Type          |
| ------------- | ------------- |
| Student Name  | Text          |
| Age           | Number        |
| Email         | Email         |
| Gender        | Radio Buttons |
| Department    | Dropdown      |
| Skills        | Checkboxes    |
| Date of Birth | Date          |
| Address       | Textarea      |
| Submit        | Button        |
| Reset         | Button        |

Use:

* Labels
* Placeholder
* Required attribute
* Proper HTML structure

---

# Part 2 – JavaScript Basics (20 Marks)

Using JavaScript,

### Task 1

Validate the form.

Conditions

* Name cannot be empty.
* Age should be greater than 16.
* Email should be valid.
* At least one skill must be selected.

---

### Task 2

After successful validation,

Display student information inside a table without refreshing the page.

---

### Task 3

Provide buttons to

* Delete Student
* Edit Student
